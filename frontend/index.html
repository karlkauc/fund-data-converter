TPT ⇄ FundsXML Converter

Free online converter for the FinDatEx Tripartite Template (Solvency II TPT V7 and V8). Upload a TPT file as Excel or CSV and get a schema-valid FundsXML 4.2.11 document: the Solvency II TPT block plus the regular fund, share class, position and asset structures. Or convert a FundsXML 4 document into a TPT file — one portfolio per share class, as XLSX or CSV.

The round trip is lossless: values FundsXML has no element for are kept as custom attributes. Every conversion comes with a report — XSD validation, missing mandatory fields, moved values. Files are processed in memory and not stored; no login, no cookies.

Reference: all TPT fields, the TPT ⇄ FundsXML field mapping, what the Tripartite Template is, TPT V7 vs V8, the conversion API and all guides.

Sister tools by the same author: Online XSD Viewer (browse the FundsXML schema), XML Online Viewer and Online OData Viewer, plus the desktop app FreeXmlToolkit.
