## About

The Fund Data Converter is a private, non-commercial project and part of the FreeXmlToolkit family of free tools.
It has no advertising and no paid plans. The source code is on
[GitHub](https://github.com/karlkauc/fund-data-converter).

The project is independent. It is not affiliated with or endorsed by FinDatEx, FundsXML or openfunds; their names
are used only to describe the formats the tool works with.
